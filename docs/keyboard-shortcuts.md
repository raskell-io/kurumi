# Keyboard shortcuts

`Cmd` on a Mac, `Ctrl` elsewhere. All app shortcuts can be changed in
**Settings → Keyboard shortcuts** (click *Change*, press the new keys;
Backspace removes one). Changes are saved per device.

## Everywhere

| Shortcut | Action |
|----------|--------|
| `Cmd/Ctrl + K` | Search / command palette |
| `Cmd/Ctrl + O` or `P` | Quick switcher (recently opened notes first) |
| `Cmd/Ctrl + N` | New note |
| `Cmd/Ctrl + D` | Today's daily note |
| `Cmd/Ctrl + G` | Graph |
| `Cmd/Ctrl + R` | References |
| `Cmd/Ctrl + ,` | Settings |
| `Cmd/Ctrl + Z` | Undo the last delete or change (outside the editor) |
| `Cmd/Ctrl + Shift + R` | Read mode |
| `Cmd/Ctrl + Shift + A` | To-dos |
| `Cmd/Ctrl + Shift + I` | Inbox |
| `Cmd/Ctrl + Shift + C` | Calendar |
| `Cmd/Ctrl + Shift + V` | Voice assistant (hold to talk) |
| `Cmd/Ctrl + Shift + F` | Focus mode |
| `Cmd/Ctrl + \` | Collapse / expand the sidebar |
| `Cmd/Ctrl + `` ` | Agent chat |
| `Escape` | Close the open menu, dialog or sidebar |

`Cmd/Ctrl + K`, `O`, `P`, `N`, `F` and `\` also work while you're typing
in a note.

## In a note

| Shortcut | Action |
|----------|--------|
| `Cmd/Ctrl + F` | Find in note |
| `Cmd/Ctrl + Option/Alt + F` | Find and replace (this note or all notes) |
| `/` | Slash commands |
| `[[`, `@`, `#`, `//` | Link, person, tag, date suggestions |
| `↑` `↓`, `Enter` / `Tab`, `Esc` | Pick, accept, dismiss a suggestion |
| Alt + click a link | Open it beside this note |

## Lists (to-dos, proposals, drafts, inbox, people, tags, topics)

| Key | Action |
|-----|--------|
| `j` / `k` (or `↓` / `↑`) | Next / previous item |
| `Enter` | Open the item, or the note it came from |
| `Space` | Select for bulk actions (to-dos, proposals, drafts) |
| `x` | Mark done (to-dos) |
| `e` | Edit (to-dos) |
| `a` / `r` / `s` | Approve / reject / snooze (proposals); `r` also rejects drafts |
| `c` | Copy (drafts) |
| `d` / `Delete` | Delete (undoable) |
| `Escape` | Clear the selection |

In read mode `/` focuses the filter. In flashcard review `Space` shows the
answer and `1`–`4` grade it.
